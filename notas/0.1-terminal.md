O diretório de trabalho é aquele em que estamos trabalhando no momento e que está aberto no terminal.

Os atalhos que aprendi são:

~ - é usado junto com o comando cd para ir para o diretório da home.
.. - é usado para navegar até a pasta-pai
. - é usado para indicar a pasta atual

Aprendi que um caminho ou árvore pode ser descrito pelo nome das pastas seguido de /. A primeira / significa a raiz. E cada nome após a / significa um degrau que vamos enveredando nesta árvore.

Comandos usados:

cd - para navegar até uma pasta
ls - para listar os arquivos dentro de uma pasta
ls -a - para listar todos os arquivos dentro de uma pasta, inclusive os iniciados por .
pwd - para mostrar o diretório atual de trabalho
cd .. - para navegar até a pasta-pai
cd ~ - para navegar até a home
echo $PWD - para mostrar o diretório atual de trabalho
echo $HOME - para mostrar o diretório da home
