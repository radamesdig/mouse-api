O modelo Pydantic é usado como uma espécie de "formulário" para validar os dados enviados pelo usuário na requisição e também serve como validador para os dados recebidos pelo usuário. 

Na prática, declaramos as classes do Pydantic e definimos os campos e tipos de cada campo. 

Caso algum dado seja omitido ou enviado em contraposição ao estipulado no modelo, é apresentado erro e informado o tipo de erro e a localização, ou seja, em qual campo o problema ocorreu, para que seja feita a correção.

Se não houver nenhum erro de validação, será criado um objeto da classe, que servirá como parâmetro da função que fica dentro da rota.

Caso não ocorra nenhum problema, o usuário receberá um código de status HTTP 201.

Nos demais casos, pode ser que o objeto da classe Pydantic nem seja criado e o usuário receba um outro código de status HTTP.

## Liga com

[por que fila](0.0-por-que-fila.md): A API se isola dos dados ruins de entrada por meio da classe Pydantic, assim como a fila isola o sistema dos fatores externos, não impedindo o fluxo de continuar. O usuário sempre receberá alguma informação na saída, como um código de status HTTP mostrando o que ocorreu com a requisição.
