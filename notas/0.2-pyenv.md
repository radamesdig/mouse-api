Eu aprendi que o pyenv foi instalado pelo homebrew, que é como se fosse uma loja de aplicativos para shell. E também aprendi onde posso acessar a pasta do homebrew para navegar pelos aplicativos instalados. 

Também aprendi que não devo usar o python do MacOS para os meus projetos e que quando uso o pyenv, passo a ter o meu próprio python. 

O comando que lista as versões é pyenv versions e o * significa qual é a versão ativa no momento. o pyenv lê a versão dentro do arquivo version e dentro dele tem o número da versão. Se o arquivo aponta para uma versão não instalada, aponta um erro. 

Shim: /Users/bruno_radames/.pyenv/shims/python3  
pyenv instalado pelo Homebrew: /opt/homebrew/opt/pyenv/bin/pyenv 
Python de verdade binário: /Users/bruno_radames/.pyenv/versions/3.12.7/bin/python3
